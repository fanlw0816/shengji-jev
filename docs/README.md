## 实测证据（`spike/`）

设计中的每个常量都来自这些脚本的实测输出，改常量前请先重跑复核。

| 脚本 | 测什么 | 关键结论 |
|---|---|---|
| `bench_capture.py` | mss 与纯计算成本 | mss 整屏 17.7ms；absdiff 0.019ms |
| `bench_capture2.py` | dxcam 与模板匹配 | 模板匹配 0.145ms/次 |
| `bench_decisive2.py` | dxcam 增量语义 | 无变化时 `grab()` 返回 `None`，0.038ms |
| `bench_truth.py` | **交叉验证** | dxcam 46.7 FPS 与 mss 地面真值 46.3 Hz 吻合 → 不丢帧 |
| `analyze_screenshots*.py` | 四区真实布局 | 十字四宫格；1 张牌 56px、2 张 72px |
| `analyze_felt_threshold.py` | 桌面色能否定位牌桌 | **不能** —— 背景与桌面同色 |
| `analyze_card_blobs.py` | 牌尺寸块筛选 | 面积是区分牌块与同形 UI 元素的唯一特征 |

**踩坑记录**：早期一次测量得出「dxcam 只有 12 FPS」，是**测量方法缺陷**
（用 `latest_frame_ticks` 计数）造成的假象。后经 mss 地面真值交叉验证推翻。
结论一律以交叉验证版本为准。
